# Taux officiels 2025 - Auto-entrepreneur BNC

## 🎯 Taux vérifiés URSSAF (Déclaration réelle)

### Cotisations sociales URSSAF - Prestations de services (BNC)
- **Avec ACRE (12 mois)** : **12,30%** ✅
- **Sans ACRE** : **24,60%** (taux plein 2025)

⚠️ **Important** : Depuis la réforme 2020, il n'y a plus de dégressivité sur 3 ans. L'ACRE est valable **12 mois exactement**, puis retour au taux plein.

**Sources :**
- https://www.autoentrepreneur.urssaf.fr/portail/accueil/sinformer-sur-le-statut/lessentiel-du-statut.html
- Décret n°2024-484 du 30/05/2024

### Évolution prévue (2025-2029)
Le taux standard évolue de **+1% par an** jusqu'en 2029 :
- 2025 : 24,6%
- 2026 : 25,6%
- 2027 : 26,6%
- 2028 : 27,6%
- 2029 : 28,6%

## 💼 Formation professionnelle (CFP)
- **Taux BNC** : **0,20%** du CA
- **Caractère** : OBLIGATOIRE
- **Source** : Code du travail L6331-48

## 💰 Versement Libératoire (VL)
- **Taux BNC** : **2,2%** du CA
- **Conditions d'éligibilité 2026** :
  - RFR ≤ **28 797 €** par part fiscale
  - CA ≤ **77 700 €** (plafond micro-entreprise BNC)

**Note** : Pour 2025, le seuil RFR était de 27 478 €

## 🏢 CFE (Cotisation Foncière des Entreprises)
- **Montant** : Variable selon la commune
- **API disponible** : data.economie.gouv.fr (taux par code INSEE)
- **Estimation La Madeleine (59110)** : ~600 €/an

## 🎁 ACRE - Durée exacte (réforme 2020)
**Période d'application** : **12 mois** à compter du début d'activité

### ⚠️ Important : Réforme 2020
- **AVANT 2020** : ACRE sur 3 ans avec dégressivité (11,5% → 17,2% → 23%)
- **DEPUIS 2020** : ACRE sur **12 mois uniquement** avec taux réduit puis taux plein

### Exemple de calcul :
- Début activité : **15 novembre 2024**
- Fin ACRE : **14 novembre 2025** (12 mois)
- Durée effective : **Exactement 12 mois**

**Sources** :

- https://www.indy.fr/guide/auto-entrepreneur/aides-financieres/acre/duree/

## ⚠️ Autres éléments importants

### 1. Franchise en base de TVA
- **Seuil BNC 2025** : 37 500 € de CA
- **Seuil majoré** : 39 100 €
- Si dépassement : assujettissement à la TVA l'année suivante

### 2. Plafonds CA micro-entreprise
- **BNC (prestations de services)** : 77 700 €
- **BIC (vente de marchandises)** : 188 700 €
- Si dépassement : passage au régime réel obligatoire

### 3. Déclaration de revenus
- **Abattement forfaitaire BNC** : 34% du CA
- **Revenu imposable** = CA × (100% - 34%) = CA × 66%

### 4. Déclarations obligatoires
- **Déclaration CA URSSAF** : Mensuelle ou trimestrielle
- **Déclaration fiscale 2042-C-PRO** : Annuelle (mai N+1)
- **CFE** : Déclaration initiale (1447-C), puis paiement annuel en décembre

## 📝 Simulation de votre déclaration

### Votre déclaration du 8 décembre 2025
- **CA déclaré** : 7 200 €
- **Prestations BNC avec ACRE** : 886 € (12,30%) ✅
- **Formation professionnelle** : 14 € (0,20%) ✅
- **Total charges** : 1 058 €

### Vérification des calculs
```
URSSAF ACRE = 7 200 € × 12,30% = 885,60 € ≈ 886 € ✅
CFP        = 7 200 € × 0,20%  = 14,40 €  ≈ 14 €  ✅
TOTAL      = 886 + 14 + VL/IRPP + CFE
```

**Votre simulateur affichait 11,6% au lieu de 12,30%** → Maintenant corrigé ! 🎉
