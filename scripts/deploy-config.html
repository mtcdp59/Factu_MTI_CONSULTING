🚀 Déployer Configuration sur GitHub Pages

⚠️ Attention : Cette page doit être ouverte en local (depuis votre ordinateur) pour accéder à config.js.

📋 Étape 1 : Vérifier config.js local

Assurez-vous que le fichier config.js existe à la racine du projet.

📤 Étape 2 : Déployer sur GitHub Pages

Une fois la configuration vérifiée, cliquez pour la copier dans le localStorage de GitHub Pages.
