Planning Google Calendar

📅 Calendrier interactif FullCalendar : Connectez-vous à Google pour gérer vos rendez-vous directement dans le calendrier (cliquer pour créer, glisser-déposer pour déplacer, redimensionner pour ajuster la durée). Plage horaire : 8h-20h, semaine du lundi au dimanche.

⚠️ Serveur HTTP requis

L'authentification Google OAuth2 ne fonctionne pas avec le protocole file://

Solutions :

  • Python : python -m http.server 8000 puis ouvrez http://localhost:8000/index.html
  • Node.js : npx http-server -p 8000 puis ouvrez http://localhost:8000/index.html
  • VS Code : Extension "Live Server" → Clic droit sur index.html → "Open with Live Server"

Vos domaines autorisés : http://localhost et https://mtcdp59.github.io
